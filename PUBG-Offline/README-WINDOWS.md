# RINX Battle Royale — Windows Offline Build

This package is a standalone desktop wrapper around the offline game in `index.html`.

## Run
- Download `RINX-Battle-Royale-Offline.exe` from the GitHub Actions artifact.
- Run it directly on Windows.
- No login, account, or network connection is required after the package is built.

## Controls
WASD move · Mouse aim · Left click fire · R reload · E loot · F vehicle · TAB inventory · G cosmetic theme · Shift sprint

The project uses original/procedural visuals and does not bundle proprietary PUBG files.
