# PUBG-Offline

Offline PUBG-inspired training project.

## Target features
- Fully offline operation
- Training mode
- Local bots
- Vehicles
- Inventory and loot
- Weapons, attachments and reload
- Local cosmetic skins
- Multiple map support
- Low-spec graphics profile

## Asset policy
Use only original, CC0, MIT-compatible, or otherwise legally redistributable assets for the standalone build. PUBG proprietary game assets are references only and are not bundled.

## Maps
The project should use locally bundled/original map content. PUBG map names may be used as references, but official proprietary map assets are not redistributed.

## Build target
Windows offline build, optimized for low-end hardware.
